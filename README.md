# NÉXORA — Plataforma Digital para la Administración Logística de Misiones Militares

Prototipo funcional desarrollado en **React + Vite** aplicando **Programación Orientada a Objetos (POO)**, control de acceso basado en roles (**RBAC**) y persistencia local mediante `localStorage`.

## Instalación y Ejecución
1. Instalar dependencias:
   ```bash
   npm install
2. Ejecutar en modo desarrollo
   npm run dev
